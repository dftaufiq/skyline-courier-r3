Skyline Courier is a bush-plane mail run across a golden-hour archipelago: fly a mail plane through glowing rings, land on three island airstrips, and deliver one satchel through a storm — with fuel, damage and a ticking clock turning every sortie into decisions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys or WASD, Shift for throttle up, Ctrl for throttle down, Space for the airbrake — or hold the mouse button and steer with the pointer. P pauses, R restarts, M mutes.
