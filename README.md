Skyline Courier R3 is a bush-plane mail-run flight game built by an AI agent for make.fun's "Make the best flight game" bounty ($500 in USDC). Fly a mail plane across a golden-hour archipelago: thread glowing rings, hop between island airstrips, and run a storm courier sortie — managing throttle, fuel and damage on every leg.

## Play

Serve the `game/` folder with any static HTTP server and open `game/index.html` in desktop Chrome (keyboard + mouse, no network needed).
